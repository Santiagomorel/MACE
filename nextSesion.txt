## 7. Gestion de Credenciales Admin del Cliente + Vault ✅ DONE

### Contexto
- Como se almacenan las credenciales de admin de lectura de cada cliente?
- Se asume access solo read-only para consultas en paneles cloud

### Decision adoptada (arquitectura.md — Bloque E, Punto 7)
- **Estrategia:** Doble capa — AWS Secrets Manager (prod) + PostgreSQL encrypted (backup)
- **Storage:** Secrets Manager path `/clients/{tenant-id}/` por cliente
- **Security:** Encriptacion AES-256 en DB, IAM role minimo, nunca en git ni logs
- **Rotation:** Manual en POC (admin endpoint), automatica cada 90 dias en prod (Lambda)
- **Zero downtime:** dual-write durante transicion
- **POC:** `.env.{tenant}` locales + DB encrypted + `SecretVaultService` con mock backend
